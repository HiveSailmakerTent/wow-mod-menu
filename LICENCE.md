## 🧩 About

**World of Warcraft helpers** is a curated list of World of Warcraft open-source tools:

- **Overlays** — on-screen helpers, layout notes, coordinate viewer, map overlays
- **Quality-of-Life Helpers** — loot tracker, inventory notes, quest helper notes
- **Research Notes** — combat rotation layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Coordinate Viewer — display player position and zone info
- Map Overlay — show points of interest and routes
- Loot Tracker — log drops and item sources
- Quest Helper Notes — organize quest objectives

### 🎨 Interface & HUD
- Custom HUD — rearrange UI elements
- Buff Tracker — monitor active effects
- Cooldown Timer — track ability cooldowns
- Range Indicator — visualize spell ranges

### 🏋️ Utility & Config
- Profile Manager — save and load configurations
- Hotkey Binds — customize overlay controls
- Safe Mode — conservative defaults for stability
